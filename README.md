# Alanım — Portföy Takip

Tek sayfalık portföy takip arayüzü. Vite ile derlenir; `dist` çıktısı GitHub Pages üzerinden yayınlanır.

## Kurulum

```bash
npm install
npm run dev
```

## Derleme

```bash
npm install
npm run build
```

Derlenmiş dosyalar `dist/` içindedir. Yayın adresi: https://mhmtatici.github.io/portfoy/
